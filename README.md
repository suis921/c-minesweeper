# 自作マインスイーパ

C言語で開発した、CUI形式のマインスイーパです。

## 概要

大学の授業課題として開発しました。
CUI環境でもゲームの状態を視覚的に把握しやすいよう、表示形式や記号を工夫しています。

## 主な特徴

- C言語によるゲーム実装
- CUIによる盤面表示
- 記号を用いた視認性の高い表示

## 使用技術

- C

## 実行方法

### 動作環境

- OS：Linux
- コンパイラ：GCC

### ビルド

ソースコードと `co.h` を同じディレクトリに配置し、以下のコマンドを実行します。

```bash
gcc -o minesweeper.out minesweeper.c
```

### 実行

```bash
./minesweeper.out
```

## 注意事項

- Linux環境向けのプログラムです。Windows環境では動作しません。
